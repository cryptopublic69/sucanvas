# Web 设置恢复修复：远端更新步骤

本更新包针对已部署的 `windows-web` 版本，修正完整备份的设置恢复时序。服务器在启动时保存导入设置，完成后才允许网页加载；不依赖网页退出或刷新时保存。

1. 停止远端 Web 服务。脚本启动的实例运行 `scripts/Stop-Web.ps1`；计划任务启动的实例从任务计划程序停止。
2. 用 `scripts/Backup-Web.ps1 -Destination <新的备份目录>` 备份当前配置和数据，同时保存旧的 `SuCanvasServer.exe`，方便回退。
3. 将更新包中的 `SuCanvasServer.exe` 覆盖到原部署目录。保留原来的 `config.json`、`data`、`web`、`tools` 和运维脚本；本次修复不需要更换网页文件。
4. 启动 Web 服务，登录后在软件备份页面导入本地版导出的 `.sucanvas-backup`。
5. 等待“恢复已准备完成”的提示，再停止并启动服务器上的 Web 服务，然后重新登录网页。
6. 人工确认方案、预设、界面设置、项目和素材；刷新网页并再次登录，确认设置仍然保留。

如果已在旧版导入过备份但设置没有保存，更新后请重新导入原备份。完整恢复会替换 Web 当前项目和数据；Web 登录密码及服务器 `config.json` 保留。ComfyUI 地址和服务器路径以 `config.json` 为准。

回退时先停止服务，将旧 EXE 和更新前的数据备份恢复后再启动。恢复脚本会保留目标服务器的配置和被替换的数据目录。
