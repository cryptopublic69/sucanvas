# 108 本地更新

在 108 本机打开 `F:\SuCanvas-Web-Update`。

1. 等待开发机把本次新包上传到 `package` 文件夹，上传完成后再操作。每次用完整新包替换旧包，不要混放。
2. 通过现有服务开关停止 SuCanvas 服务。
3. 双击 `Update-OnServer.bat`。窗口会显示执行过程，结束后保留窗口供查看。
4. 出现 `PASS` 和 `Update complete` 后，通过原服务开关启动服务，再刷新网页人工确认。

脚本在 108 本地完成完整备份、SHA-256 校验和文件替换。备份位于 `F:\SuCanvas-Web\backup\before-update-*`；配置、项目数据、代理、工具和服务开关保持原样。包内有服务 EXE 时更新完整版本，没有 EXE 时只更新网页。

如果窗口显示 `FAILED`，保持服务停止，查看 `logs` 目录的日志并反馈。缺少更新包、服务尚未停止、包校验失败时不会替换部署文件；替换途中出错会恢复原发布文件。执行结果另存为 `deployment-result.json`。

不要从其他电脑双击网络盘或共享路径里的入口。请在 108 使用本地 `F:` 路径执行，才能让备份和校验留在服务器磁盘上。脚本不会自动停止或启动服务。
